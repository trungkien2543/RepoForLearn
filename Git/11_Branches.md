# Câu lệnh

. git branch -l: xem thông tin nhánh

. git branch <branch_name>: tạo

. git checkout <branch_name>: chuyển

. git push -u origin feature-login: dùng để tạo branch mới trên remote và thiết lập upstream

✅ Quy tắc quan trọng của Git

Git chỉ quản lý file đã commit.
File chưa commit không thuộc branch nào cả.
