# Các câu lệnh trong git

## cd

- thay đổi thư mục làm việc

## dir (MS Window), ls (linux,macOS)

- hiển thị danh sách tập tin hoặc thư mục bên trong thư mục hiện hành

## mkdir

- tạo thư mục mới

## touch

- tạo ra một file mới

- muốn tạo một file mới có khoảng trắng trong tên thì phải bỏ vào cặp ''

- tạo file có tên trùng thì không tạo file mới

## echo

- giúp in một cái nội dung hoặc có thể dùng để ra một file mới

- '>' chỉ định hướng sẽ in dữ liệu

- '>>' để ghi thêm dữ liệu vào file mới

## cat

- hiển thị nội dung của file

## diff file1 file2

- tìm kiếm sự khác biệt giữa 2 file

## rm

- xóa tập tin

- '-d': xóa thư mụ rỗng

- '-r': xóa thư mục có file ở bên trong
