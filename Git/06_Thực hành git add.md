working directory 
-> git add
-> staging area
-> git commit
-> repository

. git add [file name(s)]: thêm tệp vào index
  git add . : thêm tất cả tệp

. git commit -m "nội dung": tạo commit -> repo

. git status: nhìn thấy sự khác biệt giữa 3 cây

. git diff: so sánh với commit cuối cùng

. git log: để xem lịch sử
