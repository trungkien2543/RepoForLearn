1️⃣ Fork là gì

Ví dụ repo gốc:

github.com/userA/project

Bạn fork → GitHub tạo repo mới:

github.com/yourname/project

👉 Đây là repo riêng của bạn, nhưng copy từ repo gốc.

2️⃣ Mục đích của Fork

Fork thường dùng khi:

muốn đóng góp code cho dự án open source

không có quyền push trực tiếp vào repo gốc

Quy trình thường là:

Fork → Clone → Sửa code → Push → Pull Request
