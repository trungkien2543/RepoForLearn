## Các từ khóa
- repository (repo): kho lưu trữ
- commit: một đơn vị làm việc
- branch: nhánh 
- main/master: tên của repo chính
- merge/rebase: kết hợp 2 nhánh
- develop: tên

## Một số lệnh

- git --help: mở hướng dẫn git
- git --version: hiển thị thông tin phiên bản
- git status: hiển thị trạng thái kho lưu trữ
- git log: hiển thị lịch sử các commit
- git init [repo name]: tạo ra kho lưu trữ trống
- git clone [repo name] [clone name]: tạo một bản sao được liên kết với repo
- git config -l: xem cấu hình hiện tại
- git config -l [--scope] [option_name] [value]
