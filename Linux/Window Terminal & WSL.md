> Mẹo
- Nhấn `tab` để auto complete
- Nhấn `ctrl + a` / `ctrl + e` để di chuyển về đầu/cuối command
- Chạy đồng thời nhiều commands: `command-1;command-2;command-3`, `command-1 && command-2 && command-3`
